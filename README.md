# Dikshu Ice Cream

Dikshu Ice Cream is a premium animated landing page for the DOS dessert brand. It presents a colorful flavor showcase with smooth transitions, layered product imagery, a lightweight preloader, and responsive styling for desktop and mobile.

## Brand

- Brand name: Dikshu
- Company: DOS
- Product focus: animated ice cream flavor showcase

## Features

- React and Vite single-page app
- Framer Motion flavor transitions
- Lenis-powered smooth scrolling setup
- Responsive hero layout with branded flavor copy
- Image-based ice cream and ingredient visuals

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

```text
src/
  components/       Reusable React components
  data/             Flavor content and image paths
  lib/              App hooks and animation helpers
public/images/      Ice cream and ingredient image assets
```
